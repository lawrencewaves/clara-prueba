# Clara · versión de prueba

App compilada de **Clara** (agenda, clientes y cobros para psicólogos), publicada en GitHub Pages.
Funciona sin conexión una vez instalada y guarda los datos **cifrados solo en el dispositivo** de quien la usa.
Versión de prueba: usa solo datos inventados.

Este repositorio contiene únicamente los archivos compilados; el código fuente es privado.
